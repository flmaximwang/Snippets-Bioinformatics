# Step 1: Use SolubleMPNN to generate a sequence

- Generate one sequence each time. Check this sequence doesn't exist in summary.csv

```shell

mamba run -n ProteinMPNN python /opt/envs/ProteinMPNN/repo/LigandMPNN/run.py \
    --pdb_path "node/v8-0-0_mutate_conserved.pdb" \
    --out_folder "node/candidate_8.n.0 \
    --fixed_residues $FIXED_RESIDUES \
    --omit_AA C \
    --model_type soluble_mpnn \
    --checkpoint_soluble_mpnn /opt/envs/ProteinMPNN/models/solublempnn_v_48_020.pt \
    --seed 101 \
    --batch 10 \
    --number_of_batches 1
```

# Step 2: Prediction Preparation

- Read the file generated by SolubleMPNN in seqs/*.fa. The designed sequence is the second.
- Split the original fasta into 3 fragments.
- Submit it to colabfold
- After MSA, paired/paired.a3m can be used for prediction. Extract the first sequence (query) to single.a3m because it's necessary for OpenDDE prediction
- Copy opendde_template.json and put `paired.a3m` in `unpairedMsaPath`. Put `single.a3m` in `pairedMsaPath`. DO NOT put `paired.a3m` in `pairedMsaPath`

## Example

Below is the example fasta

```fasta
>v8_0_0_split
MKGDTRTINALNETLGHMLVHINTLFLLARMAKNNGDKWLNDVLYHMSIKAMKAADKLIE
VILFLEGLPNLQDLGKLNI:SSGSGG:LINTLNILLGQQLVLINQLFLLARMAKNRGLKY
ENDVLYHLSIDAMKMADDFIELILFLEGLPNLQDLGKLNI
```

Below is the example command to submit msa. 之前的结果中，是否使用 template 结果都比较像，先不加 template, 方便一些
```sh
mamba run -n BioRazer biorazer colabfold-msa \
    -i some.fa \
    -o data/candidate-8.n.0 \
    --pair-mode paired \
    --fetch-templates False
```

# Step 3: OpenDDE prediction

## Example

```shell
mamba run -n OpenDDE opendde pred \
    -i data/candidate-8.n.0/opendde.json \
    -o data/candidate-8.n.0 \
    --need_atom_confidence True \
    --seeds 101
```

# Step 4: Consistency Check

- ptm > 0.8
- Align predicted structures to v8-0-0_mutate_conserved. Backbone RMSD < 1.5
